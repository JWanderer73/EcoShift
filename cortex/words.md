# Words

A feature is a heading in masterplan.md, plus the lines under it until the next heading.
Logic is one ordinary sentence of what a function does, written on the left.
Context is that note. The left side is what the person reads.
When an agent decides something, the note on the left changes.
When the master plan or a logic sentence changes, the prompt optimizer writes a shorter prompt before a model is asked.
Ready checks that a finished feature can be tested.
Test runs the real test command and reports pass or fail.
